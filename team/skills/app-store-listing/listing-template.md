# Shopify App Store listing template

Limits checked 2026-09-24 at https://shopify.dev/docs/apps/launch/app-requirements-checklist and https://shopify.dev/docs/apps/launch/shopify-app-store/app-store-requirements (section numbers in brackets). Re-check before each submission.

| Field | Limit / rule | Draft | Chars |
|---|---|---|---|
| App name | ≤ 30 chars; leads with our brand; unique; same as in the Partner Dashboard [4.1.1, 4.1.2] | | |
| App icon | 1200×1200 px, JPEG or PNG, square with rounded corners; no text, screenshots or Shopify marks | file: | — |
| App introduction | ≤ 100 chars; merchant benefit; no keyword stuffing or fragments | | |
| App details | ≤ 500 chars; what it does and its unique value; no heavy marketing or guarantees | | |
| Feature list | each ≤ 80 chars; what the merchant gets, not how it's built | 1. 2. 3. … | |

| Privacy policy URL | required | (from `legal-doc-draft`, published by owner) | — |

## Never in listing content [4.3]
- Statistics or data ("saves 5 hours", "used by 200 shops") [4.3.3]
- "The first", "the best", "the only" [4.3.4]
- Testimonials or reviews in designated areas [4.3.6, 4.3.7]
- Outcome guarantees; PII; pricing inside images
- Shopify brand misuse in graphics [4.4.3]

## InvAI-specific notes
- Say which channels come in through the Shopify app and which through CSV import.
- Say that buyer names and addresses are used only to print labels and packing slips and are deleted 30 days after delivery (verify the purge before claiming it).
- Etsy trademark notice if Etsy is named anywhere in the listing.
