# Go-live checklist

Copy into `invai-docs/customers/<shop-slug>/onboarding.md` and tick with evidence (a date, a screenshot path, or an issue id).

## Accounts
- [ ] Owner account created by the shop (the owner sends the invite link; we never create accounts with real emails)
- [ ] Staff invited with the right roles (**Settings → Team**): office, designer, presser, packer, receiver
- [ ] Floor PINs set by each staff member; language chosen (en/es) on the tablet
- [ ] Plan confirmed by the owner (**Settings → Billing**); pilots: 3 months free

## Data
- [ ] Channels connected or CSV format chosen (**Settings → Channels**); last dry run `ready`
- [ ] Blanks imported with costs; on-hand counts entered or accepted as unknown
- [ ] SKU rules saved; auto-map rate on the latest export ≥ target in `profile.md`
- [ ] Personalization templates checked on 5 real orders (**Catalog → Personalization**, Artwork review)
- [ ] Costs set (**Settings → Costs**) so **Analytics → Profit** isn't estimated everywhere
- [ ] Stock push decided per channel (decision 0003), and left off until counts are right

## Floor
- [ ] Every tablet paired (**Settings → Stations**, Pair tablet)
- [ ] Scanner test: transfer QR and blank barcode both read at Press; a wrong blank shows BLOCKED
- [ ] Offline test: Wi-Fi off, 3 scans, Wi-Fi on, scans replayed
- [ ] Label print test: a 4x6 PDF prints at true size on their printer

## Vendor
- [ ] DTF vendor invited (**Settings → Vendors**); the owner sent the invite
- [ ] A test sheet reached the vendor's **Sheet inbox** and the vendor confirmed its spec

## Day one
- [ ] First batch chosen (e.g. one channel, non-rush orders)
- [ ] Who to call and when (the owner); check-ins at 11:00 and 16:00
- [ ] **Rollback plan:** how they go back to the old process the same day, what happens to orders already on a sheet or labeled, who decides

## After day one
- [ ] Issues logged (`triage-support-ticket`)
- [ ] First numbers in the weekly update: orders processed, late count, film use, reprints, blocked scans
