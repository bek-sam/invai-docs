# Full codebase audit, 2026-09-24

Four read-only audits ran in parallel: backend (A-BE), frontends (A-FE), imaging/infra/contracts (A-INF) and a baseline test run (A-QA). Each finding became a backlog item (B-50 to B-108). This file keeps the evidence (file:line) that task cards cite. Line numbers are approximate (±5).

## A-QA: baseline health
- typecheck, lint and unit tests pass in all 8 repos (backend 148, floor 41, contracts 31, imaging 27, web 23, ui 20).
- **`invai-backend` `pnpm build` fails**: `CACError: Unknown option --noExternal` (tsup 8.5.1). The Dockerfile, compose `full` and SST services depend on it (B-56).
- E2E: green when run in a clean sequence (fresh seed → API 13/13 → wait 65 s → web 15/15 → floor 1/1).
  - Flaky: `golden-path.spec.ts:238` step 6, since `clickIfShown` uses `isVisible()` without waiting (B-97).
  - The sign-in limit (20/min/IP, `auth.ts:86`) makes back-to-back suites fail with 429 (B-97).
- `db:seed` can fail while the worker runs (`stock_levels` unique violation at `seed/index.ts:1442`) (B-106).
- Runbook is stale:
  - Seeding takes about 25 s and makes 360 orders.
  - Imaging must run before the seed.
  - The worker must be stopped during the seed.
  - E2E steps aren't documented.
  - `pnpm stop` doesn't stop the app processes.
- Bundles: web `env-*.js` is 607 kB and floor `index-*.js` is 818 kB.
