# T-7-5: Accessibility and i18n sweep (B-93, B-42)
## Owned paths
- invai-ui (`data-table`, `app-shell`, `pin-pad`, `relative-time`, `money`, `command`, `file-drop`)
- web `lib/errors.ts` (generic messages), `routes/signup.tsx`
- own i18n keys
- web `main.tsx` (the toast suppression for `PLAN_LIMIT_REACHED`, `PAYMENT_REQUIRED`, `CREDITS_EXHAUSTED`, `EMAIL_NOT_VERIFIED`)
- tests

## Acceptance criteria
1. **Tables:** clickable rows are real links or buttons, keyboard reachable, with an accessible name.
2. **Skip link:** a skip-to-content link.
3. **Locale:** `RelativeTime` and `Money` use the app locale ("hace 4 semanas").
4. **No English:** no hard-coded English left in invai-ui or the web error messages (grep proof in the report). The untranslated Spanish values are fixed.
5. **Toasts:** the global toast is suppressed where a dialog already explains.
6. **Checks:** run axe on 5 key pages (Today, Orders, Order detail, Shipping, Billing); no serious or critical issues.

## Verify
Run tsc, lint, test and build in ui and web. Run axe with Playwright on a DB copy, and screenshots in es.
