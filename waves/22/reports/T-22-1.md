## Decisions
- **New permission `production.maintenance`** (owner, admin, office) instead of reusing `stations.manage`: office lacks `stations.manage` (it issues station tokens, owner/admin only), yet T-22-4's verification has `office@` ending maintenance; presser and packer hold identical floor permissions, so no existing permission refuses a packer and allows a lead. Recorded in `roles.ts` comment and CHANGELOG.
- **Maintenance idempotency by result shape** (`started`/`ended` booleans), so a retried start/end never throws; errors are reserved for real faults.
- **Scan at a closed station = `ScanResult` with `station_maintenance`, `nextAction: "press"`** (A4); `NEXT_ACTIONS` unchanged so no floor switch breaks.
- **Blank location nested under `blank`**, not top-level `binCode` (collision with the pack tote).
- **`verifyAddress` is `shipping.manage`** (not `orders.manage`): a carrier-side call made from the shipping module; the hold on `failed` is a side effect the service performs. Same holders either way.
- **`Rate.expiresAt` optional**, not nullable-required: keeps today's backend green; absent = unknown = still valid on the client, the server judges on `buy`.
- **ADR 0017** (`invai-docs/decisions/0017-listing-attributes-shape.md`, accepted): attributes stay a map; the list is model transport. Index row added.
- **Three commits, two reverted on main**: see "Built". Version stays 0.8.0 for all.
- Cited TikTok source fetched live (WebFetch, 2026-09-28) and cross-checked with T-7-2.
