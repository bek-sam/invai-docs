## Acceptance criteria
1. QC fail through the existing `production.qc` takes a `reprintReason` (per T-22-1); the reprint it creates carries the mapped reprint reason; the reasons report counts them.
2. Transfer age: `printedAt` is set when a sheet is received/printed; pick and press views return `ageDays`; a transfer older than the org's setting (default 30 days) returns a warning flag (DTF transfers lose adhesion with age); no block.
3. Maintenance block (new production-owned table `station_maintenance_events`): starting maintenance on a station makes its press scans return a blocked `ScanResult` with mismatch reason `station_maintenance` until ended; start/end are idempotent and audited; the floor's offline replay of a blocked scan parks it with that reason.
4. Pick list lines return the blank's bin code and shelf when a bin exists (B-32).
5. Tenant-isolation tests for the new columns/procedures; the floor golden path (`invai-floor pnpm e2e`) still passes against your API.
