## Acceptance criteria
1. Each tool follows the spec's input and output table. Money in cents, ratios 0..1 in `data`, formatted in `answer`/`summary`. Every result is capped (≤ 20 rows per list).
2. **compare_periods:** with no previous range given, the previous period is the same length immediately before. Per-channel contributions to the revenue and net change add up to the total change.
3. **get_ad_performance:** ROAS = channel revenue ÷ ad spend (null when spend is 0); TACoS = ad spend ÷ total revenue; `attribution: "channel"` is in `data`. Campaign grouping returns spend and share only.
4. **get_design_insights:** rising, falling, low-margin, top-net and cross-listing gaps as specified. A cross-listing gap only names channels that the shop has an active connection for.
5. **get_fulfillment_health:** on-time rate per channel (`shippedAt <= shipBy`, shipped orders only), open overdue now, median hours placed → shipped, reprints by reason (rate per item), refunds (voided excluded) per channel.
6. **Tenant isolation:** a test seeds two companies and proves each tool returns only the caller's rows.
7. **No buyer PII:** no names, emails or addresses in any `data` (test asserts on the keys).
8. **Correctness:** tests check each tool's numbers against hand-built fixtures (not against the same SQL).
9. **Mock provider:** keyword routing picks the new tools, so the platform works with no key ("ads" → `get_ad_performance`, "compare"/"vs"/"why" → `compare_periods`, "rising"/"designs" → `get_design_insights`, "on time"/"late"/"reprint" → `get_fulfillment_health`).
10. **Evals:** add at least 2 cases per new tool to `evals/assistant/cases.jsonl` (including one injection case with a hostile design name). Run the assistant evals in mock mode and update the baseline.
11. Existing assistant tests pass unchanged.
12. **Small shops (spec AC9):** a shop with one channel and no ad spend gets clear answers, not errors: `get_ad_performance` says there is no ad spend, and comparisons handle zero revenue. Test with a single-channel, no-ad fixture.
13. **Disconnected channels (spec AC10):** a channel whose connection is inactive is left out of cross-listing gaps, and the output sets `incomplete` with the reason.
