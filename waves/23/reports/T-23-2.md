## Decisions
- No new floor-side state machine or outbox logic for AC2: the existing generic mismatch/blocked/alert path
  already covers any `MISMATCH_REASONS` value, so the whole AC reduced to two translation strings.
- Camera scanner uses the browser's native `BarcodeDetector` only, not the `barcode-detector` npm ponyfill
  already sitting in `package.json` (unused, pre-existing) — importing its WASM ponyfill would risk the
  bundle budget for a feature the card called "optional"; native detection has zero bundle cost.
- `vite.config.ts`/`nginx.conf.template` Permissions-Policy change: see "Built" above.
