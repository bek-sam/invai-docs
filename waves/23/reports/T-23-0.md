## Round 2 (2026-09-29)

Fixes the round-1 blocking finding: `redisDbIndex` used `Number(path)`, which reads several
non-canonical DB-0 spellings as "non-zero, so already pinned" — `/0/` (`Number("0/")` is `NaN`),
`/0.5` (`Number` parses decimals), `/0x1` (`Number` parses hex strings, giving `1`) — and left them
unredirected, so a `REDIS_URL` written that way would run the suite on live DB 0.

### Built
- `src/env.ts`: replaced `redisDbIndex()` with `isPinnedNonZeroDb(url)`, which keeps a URL
  unchanged only when its path matches `^[1-9]\d*$` exactly (no path, `/0`, `/0/`, `/0.5`, `/0x1`,
  blank or non-numeric text all now redirect to DB 15). `withTestRedisDb` uses it.
- `src/env.ts`: added `assertTestRedisDbPinned(url)` and applied it to `TEST_REDIS_URL` (round 1 used
  `raw.TEST_REDIS_URL` verbatim, with no check). A `TEST_REDIS_URL` that isn't a pinned non-zero DB
  now throws a clear error at boot (`TEST_REDIS_URL must point at a non-zero Redis DB ("<url>"),
  never DB 0 …`) instead of silently running on DB 0. Chose throw over silent redirect: an operator
  who explicitly set `TEST_REDIS_URL` to DB 0 almost certainly made a typo (meant `/14`, wrote `/1`
  as `/0`, etc.), and a loud failure at boot is safer than a quiet DB-0 collision that only shows up
  as flaky test interference later.
- `src/test/redis-test-db.test.ts`: added 5 tests — `/0/`, `/0.5`, `/0x1` each redirect to `/15`
  (asserted on the literal returned pathname, not `dbIndex(url) !== 0`, since that check itself
  would pass on the round-1 bug for `/0x1`: `Number("0x1")` is `1`, already non-zero even
  unredirected); and two cases where `TEST_REDIS_URL` is DB 0 (`/0` and `/0/`) both refuse to boot
  with the documented error message.
- `.env.example`: added a commented `#TEST_REDIS_URL=redis://localhost:6379/14` line next to
  `REDIS_URL`, matching the existing `TEST_DATABASE_URL` pattern (this file is inside
  backend-foundation's owned paths per the role file, though not named on the card's path list).
- `README.md`: reworded the redirect paragraph to state the exact rule (`^[1-9]\d*$`, not "a
  non-zero DB you set") and to document that a DB-0 `TEST_REDIS_URL` now fails the boot.
