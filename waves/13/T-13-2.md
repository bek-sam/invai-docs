# T-13-2: Contract CI and versioning (B-83)
## Acceptance criteria
1. **Consumer CI:** invai-contracts CI typechecks backend, web and floor against the contracts PR commit (checkout of the siblings, linked). A breaking change fails CI.
2. **Versioning:** semantic versioning with a CHANGELOG. Every contract change bumps the version (a script checks it).
3. **Local command:** `pnpm check:consumers` in contracts runs the same check locally.
4. No deploy steps (wave 10 is deferred). CI only.
