## Acceptance criteria
1. Multi-stage builds, base images pinned by digest, non-root `USER`, `HEALTHCHECK`, no secrets or `.env` in any layer (`docker history` check), smallest reasonable runtime.
2. The backend image runs api, worker and the three CLIs by command; `drizzle/` inside it.
3. `docker compose --profile full up` runs api, worker, imaging (with `IMAGING_ENV=development`, `IMAGING_DEV_ENDPOINTS=true`), web and floor (static, behind a small web server) against the local Postgres/Valkey/MinIO, with a one-off migrate service using the CLIs.
4. Disk: the Mac has about 10 GB free. Build one image at a time, `docker image prune` your own dangling layers after, and report sizes; stop if free space drops below 4 GB.
5. The golden path runs against the `full` profile (`E2E_API_URL`, `E2E_WEB_URL`, floor URL) once, at the gate (not by this card).
