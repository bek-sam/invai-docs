# Report: T-P5-5 Web shows Today alert lines and timeline reasons from codes, in English and Spanish
Author: web-engineer on claude-opus-5.5

## Built
- `AlertsPanel`'s detail line builds from `messageCode`+`params` with `t()`, through a `Partial<Record<AlertMessageCode,...>>` lookup (never an exhaustive switch, per ruling R1), falling back to today's title/message behavior when either is missing. Dates format with `Intl` in the alert's `timeZone` + active language; hours pluralize (`_one`/`_other`). (invai-web/src/routes/_app/index.tsx)
- Order timeline: a `state_changed` entry with `reasonCode` gets a translated label (`timelineReasonLabel`), reusing the existing `holdReason.*`/`cancelReason.*`/`reprintReason.*` catalogs; no code falls back to `extractTimelineReason`. (invai-web/src/features/orders/timeline-reason.ts, order-detail.tsx)
- 38 new i18n keys (`alerts.line.*` ×16, `orders.timelineReason.*` ×22) hand-added to en.ts, es.ts and scripts/i18n-es.json (key sets verified to match exactly across all three).
- Fixed a real Spanish bug found while screenshotting: `order_at_risk`'s line ended in a literal "." right after the Intl-formatted date, producing "4:30 a.m.." (Spanish "a.m." already ends in a period). Dropped the trailing period from that one template (en+es+json).
