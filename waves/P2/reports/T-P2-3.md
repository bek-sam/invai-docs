## Decisions
- Used `expect(...).toPass({ timeout })` instead of `expect.poll(...)` with a custom message option:
  Playwright 1.63's `expect.poll` has no `message` parameter (checked `playwright/types/test.d.ts`),
  but `toPass` retries a callback and rethrows whatever it last threw, so the thrown `Error` carries
  the exact count and URL.
