# Report: T-P2-1 Catalog grid loads thumbnails only when on screen

Author: web-engineer on Sonnet 5. Commit: `invai-web@7c243f9`

## Built
- `src/hooks/use-in-view.ts`: `useInView(rootMargin="300px")` (IntersectionObserver).
- `designs.index.tsx`: extracted `DesignCard`; `SignedImage` mounts (requests a signed URL) only
  once near viewport. Off-screen cards render a plain `bg-muted checkerboard` box, never
  `Skeleton`/`.animate-spin`. `analytics.designLifecycle` now calls `orpc...call({})` directly.
- `signed-image.tsx`: `useSignedUrl` also calls `orpc.files.downloadUrl.call()` directly. Root
  cause of the AC32 abort wasn't only volume: `.queryOptions()`'s generated `queryFn` always reads
  `context.signal`, so the in-flight fetch is aborted the instant the last observer unmounts (any
  navigation). Bypassing that lets it finish quietly instead of surfacing as `net::ERR_ABORTED`.
  All 8 call sites only read `.data`/`.isPending`/`.isError`, none depend on cancellation.

  zero aborts and the lazy-thumbnail fix alone doesn't cover it since `Skeleton` today has no
