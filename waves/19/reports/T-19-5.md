## Decisions
- D8 win `templateKey`: the contract has no enumerated values and the spec's Copy table has no win
  row. Chose `win.best_net_week` / `win.on_time_record` / `win.design_milestone` with a generic
  fallback for anything else, so an unmatched key from T-19-3 never shows a raw key or blank space.
  Confirmed in the live pass that this week's `win` was `null` (D8 didn't fire), so the choice
  wasn't exercised against real data; flagged in `reviews/T-19-1-web-engineer-r1.md` for the tech
  lead to reconcile with T-19-3 (backend `bef6158` uses `templateKey: "D6 action"` style keys for
  D1-D7, i.e. the literal spec Copy-table row text — worth checking whether T-19-3's win rows use
  the same "spec-table-text" convention rather than my `win.*` dot-keys; if so this needs a
  follow-up to align).
- `href` parsing: the contract's `DigestAction.href` is a combined path+query string
  (`"/orders?view=overdue"`, confirmed live). Split it locally (`parseHref` in `insight-card.tsx`)
  into TanStack Router's `to`/`search` rather than passing the whole string as `to`, since
  `AnyLink` (the existing runtime-path helper) takes `to` and `search` separately.
- "Ask the assistant about this week" links to `/assistant` plainly. `assistant.tsx` isn't in this
  card's owned paths and has no search-param handling to scope a conversation to a week, so I
  didn't add one (would need a grant). See "Known gaps".
- Preview rate-limit and `NO_DIGEST` messages built locally in `notifications.tsx` (same pattern as
  `shipping.tsx`'s `voidErrorMessage()`), not in `src/lib/errors.ts` (not owned, and no existing
  `RATE_LIMITED`-with-`retryAfterSec` message pattern was actually there to reuse — see the T-19-1
  review's note on this).
- `nav.ts`: added a `digests` entry beyond the card's explicit "settings-nav entry" grant, because
  AC2 requires `/digests` to list past weeks and it would otherwise be unreachable except from the
  Today card's link straight into one week. Minimal, single-line addition; flagged here plainly
  rather than silently widening scope.

  owns `format.ts` generally. Filed here for the tech lead rather than edited out of scope.
