## Decisions
- `digest.get` keys by `weekKey` as a **query param** (`GET /digest/week?weekKey=`): `contract.test.ts` only allows id-like GET path params.
- Market watch items are `DigestInsight`s with `detector: "market"` carrying the full `MarketRecommendation` (not the short `RecommendationRef`) so T-18-5's vote cards render without a second call; a promoted item sits in `actions` and does not repeat in `marketWatch`.
- `DigestFact.formatted` carries both `en` and `es` so the AI summary can only reference facts by id and every rendered number is code-formatted (P1).
- `EMAIL_SKIP_REASONS` is a contract enum (mirrors `sendUserEmail` reasons + `quiet_hours`) so `DigestPreviewResult` and T-19-3's delivery rows share one list.
- `aiSummary: true` is stored even in shadow (the web disables the toggle; the value takes effect only when the global mode is `on`); no extra error.
- ADR 0016 records the auth-less link routes and kind-keyed preferences (cross-cutting: backend-foundation implements, web consumes).
