# Waves

Each wave is a folder: `waves/<n>/` holds `wave.md`, one card per task (`T-<n>-<k>-<slug>.md`) and `reviews/`. Copy the files in `templates/`. The process is in `team/operating-system.md`.

Rules:
- At most 5 cards per wave, and at most 3–4 agents running at once.
- Every card has a scope reference, one owner, owned paths, acceptance criteria, verification commands and a reviewer.
