## Decisions
- Shortened Spanish pill copy rather than only adding CSS, because `whitespace-nowrap` alone
  (without shortening) would have let the pill overflow the header's available width instead of
  wrapping — still a real-world layout problem at 1280 px with every other header element present
  (operator name, "En línea", camera button, "En vivo", EN/ES, "Cambiar", menu). Shorter copy
  reusing the existing "enviar" word (glossary-safe, already used in `outbox.title: "Sin enviar"`)
  fixes the 1280 px case outright; the CSS change is defense-in-depth so the pill itself never
  wraps internally again even under future header crowding.
- Left `outbox.status.parked` ("Necesita revisión", no count, used only in the detail sheet where
  there's room) untouched — only the header-badge keys needed shortening.
