3. **B-131 regression** (`signals.ts:230-244`): an all-zero series fits a flat ln(y+1)=0 trend, so every ratio is exactly 1 and `overall` is 1, not `<= 0` — the existing guard never caught it, returning a flat SI instead of `null` and short-circuiting the Census fallback. Added an explicit `sorted.every((p) => p.value === 0)` check before the OLS fit. New test confirmed failing on pre-fix code (same revert/re-run/restore method).
