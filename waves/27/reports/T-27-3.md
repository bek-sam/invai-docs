## Decisions
- Scene job on the `ai` queue: the 120 s provider call is async, so BullMQ keeps renewing the 90 s lock. A stalled re-run reuses the stored scene; only a call cut off mid-flight can be paid twice.
- Drift on attempt 1 re-composites every channel image from the new scene (one scene per composition); attempt 2 records each image's own result.
- Base view `lifestyle_base` at 1024 px for every kind; imaging cover-fits to each preset.
- A later push of the same files records `already_pushed`. getSet shows the latest 50 pushes.
