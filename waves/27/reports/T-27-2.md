- `POST /photo/scene-composite`: untrusted-scene intake (≤ 25 MB by storage size before download, PNG/JPEG/WebP magic, 256-4096 px a side, decode pixel cap → 400), registration (cover fit, then scale 0.90-1.10 and shift ≤ 8%, by FFT masked NCC of edge maps), check 1, one `lbb` warp straight to the preset size, blank print area restored and lit by the scene, design at real size with displacement and shading from the scene, wave 26 underbase rule, check 2, then the preset and XMP `dc:subject`. A failed check writes nothing (`key: null`). `amazon_main` is refused (422).
- Both routes are in `HEAVY_PATHS` (app/guard.py). `photos.layer()` was pulled out of `photos.compose` so both can use it (no behavior change: 184 tests green).

## Interface for the backend client (T-27-3)
- scene-base request `{garment, view: on_model_white|lifestyle_base, blank_hex, size_px: int | [w,h] (256-2048, default 1024), out_key (.png), mask_out_key (.png)}` → `{key, mask_key, print_box_px: [x,y,w,h], width_px, height_px, protected_box_px, ppi}`. Ask for the base at the provider size (1024, [1536,1024] or [1024,1536]).
- scene-composite request `{scene_key, base_key, print_box_px, design_key, design_width_in, design_height_in, placement: "front", blank_hex, preset, out_key, xmp_subjects ≤ 20, optional garment, view, underbase_preview}` → `{key|null, checks: {passes, failures: ["region_changed"|"design_drift"], region_unchanged_score, design_lock_score|null, region_unchanged_min, design_lock_min}, width_px, height_px, format, print_box_px, preset_failures, registration, upscale, upscale_method: "lbb", underbase_applied, bytes, render_ms}`. Wave interface fields are all present; the rest are additions. Errors: 400 for a refused scene or keys outside the company; 422 for everything else.

## Decisions
- numpy added (pyproject + uv.lock): FFT registration and a small SSIM, instead of scikit-image (much larger, pulls scipy). pyvips `.numpy()` already expects it.
- Upscale method `lbb` (locally bounded bicubic) combined with the registration in a single resample, so nothing is resampled twice.
- Preset checks (`background_not_white`, `too_small`, `design_larger_than_print_area`) are reported in `preset_failures` and don't block the write. Only the two lock checks block.
