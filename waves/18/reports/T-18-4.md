## Built
- **Four market tools**, read-only, one `withTenant` per call, ≤ 20 rows, ≤ 3 recommendations per tool (`src/modules/ai/assistant-tools.ts`):
  - `get_market_trend` and `get_seasonality` take a design, a niche, or nothing (the shop's top 8 designs by 90-day units).
  - `get_price_position` and `simulate_price` take an optional design and channel (default: the best seller, on its main channel); `simulate_price` accepts at most 8 prices.
  - Data is copied field by field from the contract shapes (no licence, fetchedAt or anything seller-shaped). Money stays in cents in `data`.
  - The `answer` is fixed code-written copy in en or es (tool input `lang`), covering: source and date lines, `(Sample data)` on mock sources, `rec.sample`, band labels, `stale.note`, `disagree.note`, `unavailable.price`, `season.census`, `tm.dropped`, and "Not enough data" with the reason.
  - A market-service error becomes a plain tool answer. Another shop's design id returns `not_found`.
- **Niche resolution:** matches by key or label, en or es, singular or plural. A term outside the taxonomy goes through `screenMarketTerms`:
  - if dropped: the `tm.dropped` answer, no lookup, no echo; the term travels internally as `forbiddenTerms` (stripped before the model and the web see the result);
  - otherwise: an "unknown niche" answer.
- **Recommendations per tool:** trend shows R4/R5, seasonality R1, price position R2, simulation R3, all at medium band or better. For a niche question, a design's recommendation counts when the design is in that niche (`market.getDesignNiches`). R1 has no-channel and no-blank copy variants (`src/ai/market-copy.ts`).
- **Answer check in the gateway**, for turns that call a market tool (`src/ai/gateway.ts`, `src/ai/validators/answer.ts`):
  - The text is held back and checked. Every number and date must come from this turn's tool data: JSON numbers (also as dollars from cents, and percent from ratios, rounded to the answer's precision), ISO dates, the tools' own summary and answer text, the InvAI shop context, and the fixed copy.
  - These never count: numbers inside shop-typed strings (tags, names) and numbers the user typed.
  - Mock sources require "Sample data" / "Datos de muestra". Outside facts require a date. The answer must never contain a dropped term, and must not call a dropped niche "not enough data".
  - On failure: regenerate once, with the reasons (numbers only) added to the context block. The cached system prefix stays unchanged, and the second pass's tool events stay internal. If that also fails, the fallback is the tools' own answers, deduplicated.
  - Both passes are charged on one `ai_jobs` row. Turns without market tools stream exactly as before.
- **Gateway cost** is now priced by the model that answered (`tokensToCostCents(usage, result.model)`), so Haiku calls are priced at Haiku rates.
- **Stream and storage** (`src/modules/ai/service.ts`, the granted hunks):
  - `tool_result` carries `mock`, `sources` and `recommendations` for market tools only; wave 17 events are unchanged.
  - `recordRecommendationsShown({ids, shownIn: "assistant", refId: messageId})` runs once per turn, in its own transaction; a failure is logged and never breaks the turn.
  - `assistant_messages.toolCalls` stores `{calls, recommendations, mock}`, and `getConversation` returns `recommendations` and `mock` (`storedRecommendations`, which checks each entry against the schema).
- **Message order fix:** a turn's user and assistant rows share `createdAt`. History and `getConversation` now tie-break user-first, which fixes the intermittent T-17-3 follow-up failure (`74268c3`).
- **Niche route:**
  - `market_niche` runs on `claude-haiku-4-5` with `effort: null`. The provider then sends no thinking, no effort and no refusal-fallback beta (Haiku 4.5 rejects effort and adaptive thinking, per the claude-api skill); structured output and the `stop_reason` check stay.
  - Niche prompt `market_niche@1`: name and tags go in a `design` data block, taxonomy keys in `niche_options`, under the data rule.
  - `classifyDesignNiche` goes through `runStructured` and returns null on `CREDITS_EXHAUSTED` or `AI_SPEND_CAP_REACHED`. A refusal or bad output gives `{niche: null, confidence: 0}`, and a key outside the taxonomy is never returned.
  - A deterministic mock (`mockNiche`). `AI_JOB_KINDS += market_niche`; no migration (`db:generate`: "No schema changes").
- **`screenMarketTerms`:** a deterministic class-25 check, no model call. It drops a term at risk ≥ 60 and logs only the count.
- **Prompt v5** (`src/ai/prompts/index.ts`): "only market facts from market tools", plus the market rules (lang, numbers checked, source and date, Sample data, band, thin data, disagreement, stale, trademark_screen, no sellers).
- **Mock routing:**
  - trend / trending / tendencia / niche / nicho → `get_market_trend`;
  - holiday / season / halloween / get ready / temporada / fiestas / prepar → `get_seasonality`;
  - priced / price position / precio / pricing → `get_price_position` + `simulate_price`.
  - The mock also picks up the channel, the language, and a niche (holiday words, "X niche", "nicho X", quoted text).
- **Evals:**
  - `evals/market/` has 21 cases, a seed (two shops shaped like Desert Bloom, one with an injection tag), a runner and its own entry point `evals/market/main.ts`.
  - The runner re-runs the answer check on the final text, checks "Sample data" on mock results, ≤ 3 recommendations, and each case's must / must-not strings.
  - `evals/baseline.json` has the assistant and market entries.

## Decisions
- **Credit kind:** niche calls are charged as the existing `sku_suggestion` credit kind, because the contract's `CREDIT_KINDS` has no `market_niche` and a new database value would break the ledger's output schema. The `ai_jobs.kind` is `market_niche`. The architect should add `market_niche` to the contract `CREDIT_KINDS`; I'll then switch.
- **Trademark screen threshold:** 60, the listing hard gate, not 25. I measured all 438 taxonomy labels and queries: at 25 the screen dropped "St. Patrick's Day" (a real niche label), "easter bunny shirt", "groomsmen shirt" and "dad joke shirt" on fuzzy matches. At 60 none of them drop, and exact marks (Disney, Mickey Mouse) still score 70–85.
- **Fallback text:** the fallback uses the tools' `answer` sentences (code-written, with source, date and sample labels), not the one-line `summary`. The summaries lack the facts the user asked for.
- **Numbers the user types never license an answer number.** A price the user asks about reaches `simulate_price` and comes back in its data, so it is still allowed.
- **Market eval entry point:** `evals/market/main.ts` stands alone, because `evals/run.ts` is outside the card's paths.
