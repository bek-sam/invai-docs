## Acceptance criteria
1. Given the contract at 0.6.0, when the web and floor typecheck against it unchanged, then both pass (every change is additive; new event fields optional). Floor's `FLOOR_COMPAT_BASELINE` is unchanged (decision 0012).
2. Given the permission meta, then: `niches.get`/`taxonomy` use `catalog.read`, `niches.set` uses the new `market.niches.manage` (owner, admin, office, designer); presser, packer, receiver, vendor are refused all of them; recommendations list/vote require `finance.read` (designer refused). A contracts test asserts this matrix from `roles.ts`, and `contract.test.ts`'s pagination rule passes for `market.recommendations.list`.
3. Given `market.recommendations.vote` called twice with the same `{id, vote}`, the contract documents it as idempotent (one vote; the latest vote wins) and the output returns the stored vote.
4. Given the schemas, money is integer cents, confidence is a 0..1 ratio plus a band, dates are ISO strings, every outside fact carries `SignalProvenance` with `mock`, and `PricePosition` has `available: false` with a machine-readable `reason` (`no_compliant_source | not_connected | too_few_comparables`) plus `n`.
5. `niches.set` accepts at most 2 niche keys, validated as non-empty strings (the key list lives in the backend data file; the contract doesn't hard-code 64 keys), and an empty array clears the correction.
6. ADR `0015-global-market-cache.md` (architecture, `accepted` after security-reviewer's co-review): the one table allowed without `company_id` is `market_series_cache`; it holds only `(source, query, granularity, period, value, asOf, fetchedAt, licence, mock)` where `query` is a canonical taxonomy query; no tenant id, no free text from any shop; public-read RLS like `trademark_marks` (`publicReadPolicy` + `.enableRLS()`, app role select-only); written only by `withSystem` in the nightly job; unique index `(source, query, granularity, period)`; `query` validated against the taxonomy in the job and a test; retention (weekly 7-day / Census 30-day TTL, purge periods older than 5 years); the mock visibility rule from `wave.md` (say in one line that `env.allowMocks` is the existing ops-only `ALLOW_MOCKS` flag, not a new bypass; PM plan review). Enforcement named: `rls-coverage.test.ts` (`PUBLIC_READ_TABLES` + the app-role-cannot-write list) plus a market test asserting no tenant column and taxonomy-only queries. Consequences name owners.
7. `CHANGELOG.md` lists every addition.
