## Acceptance criteria
1. **Mocks for every outside source:** Google Trends, Pinterest Trends, Amazon pricing/catalog, Walmart pricing insights, Jungle Scout. Given the same query twice (and across processes), a mock returns identical series (seeded from a hash of the query, no `Math.random`, no wall-clock except `asOf`). Series carry built-in seasonal shapes: Q4 peak, Mother's Day (May), back-to-school (Aug), Halloween (Oct), plus flat and declining shapes so trend tests have both directions. Every result has `mock: true`.
2. **Census:** a real client for Monthly Retail Trade NAICS 448, not seasonally adjusted, monthly, 10 years, used only when `CENSUS_API_KEY` is set; otherwise the recorded fixture with `mock: true`. You may make one keyless GET to the public Census API to record the fixture (public dataset, no account, no data sent); if it fails, build the fixture from the documented response shape and say so in the report. No other real outside calls anywhere in this card, including tests.
3. **Selection:** a demand provider is real only when its key is set (else mock, `mock: true`). A pricing provider for a sample workspace (`isSampleWorkspace`, not `companies.demo`) is always the mock even with a key set (AC22). `marketPricingProvider` returns a provider only for Amazon and Walmart, only when the connection is active; it returns `null` for Etsy, TikTok and Shopify (fence).
4. **Real adapters are skeletons behind the interface** (Google Trends, Pinterest, Amazon, Walmart, Jungle Scout): each has a 10 s timeout, a per-provider rate limiter, retry with jitter on 429/5xx, and throws `UnrecoverableError` (BullMQ) on 401/403. They are never selected in this build because no key exists; unit tests cover the error mapping with a stubbed `fetch`.
5. **Outage switch:** `MARKET_MOCK_FAIL=google_trends` makes that mock throw a typed provider error, so T-18-3 can test AC20; other sources keep working.
6. **Provenance on every datum:** `source`, `licence` (`first_party | official_api | public_dataset | licensed`), `fetchedAt`, `asOf`, `requestKey`, `mock`.
7. **No other sellers' identities leave the provider:** mock Amazon/Walmart raw fixtures include seller names and listing titles (to prove they're dropped); the provider output `Comparables` contains only prices, featured flag and offer counts (spec AC13). A unit test asserts no seller name, title or URL field survives.
8. **Demand queries are taxonomy strings only:** `DemandProvider.series` accepts `queries: string[]`; the function doc says callers pass canonical taxonomy queries; no provider accepts free text from a shop.
