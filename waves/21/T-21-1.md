## Acceptance criteria
1. Each document starts with "DRAFT for counsel review. Not in force." and a list of the owner decisions it needs (company legal name, address, governing law, prices) as `[[OWNER: …]]` placeholders, never invented values.
2. Privacy policy and DPA state the real data flows, checked against code with file references in a trailing "Evidence" section: buyer PII fields stored (`buyer_pii`), purge 30 days after delivery (shipped/cancelled + 30 fallback), 18-month non-PII retention, tenant export and deletion (wave 12 T-12-4), AI calls without buyer PII, email only by opt-in, Mailpit/mock state noted.
3. Sub-processor list: every outside service the code can call (AWS, Anthropic, EasyPost, Stripe, Shopify, S&S, the email provider as `[[OWNER: provider]]`, error tracking if any), with purpose, data categories, region placeholder, and whether it is live or mock today.
4. Vendor inventory (for the Amazon and Shopify questionnaires): the same list plus access owner, key location (SST secret name), rotation rule.
5. Spanish versions are complete translations, marked as such; plain language; no "secure/compliant/guaranteed" claims.
