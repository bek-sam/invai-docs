## Decisions
- Included Shopify in the public sub-processor list per the card's explicit AC3 wording, but added a note
  distinguishing it from a classic GDPR sub-processor (the Shop's own authorized account, not InvAI directing

  cross-cutting decision — a documentation judgment call inside this card.
- Listed the market-signal APIs (Census, Google Trends, Pinterest, Jungle Scout) in subprocessors.md under "no
  sub-processor identified for personal data" rather than the main table, since they receive aggregate market
  queries only, never buyer or Shop PII — verified against `invai-backend/src/env.ts:100-107`.
- Did not invent an AWS region, RDS backup window, or email provider; each is an explicit gap rather than a
  guessed "us-east-1" treated as fact, even though `S3_REGION`'s code default is `us-east-1`.
