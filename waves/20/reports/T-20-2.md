  two pre-existing unit tests whose fixtures had gone stale relative to the new rule: one in
  `recommendation-copy.test.ts` set `peakMonth` with no `actByDate` (which, before wave 20, was the

  it stays a genuine "before peak" case; rewrote the FORBIDDEN assertion to the new message) rather
  than leaving `pnpm test` red — these are co-located unit tests for files inside my owned grant, not
  QA's acceptance suite. Flagging per `respect-ownership` since the card's grant text said "the R1
  'before {{peak}}' line only" in `recommendation-copy.ts` without mentioning its test file.
- **Local `GlanceTile` instead of `StatCard`.** See Built/AC2; chose to build locally per
  CLAUDE.md ("a missing component or API: build it locally, report it") rather than pass an
  unsupported `deltaDirection` value or omit the delta text (which the e2e test requires to be
  present, with no arrow, for the unchanged case).
- **Spanish date locale `es-MX` for `weekOfLabel`, bare `es` for `localeNumber`.** Followed T-20-1's
  own documented precedent (`es-MX`/`es-US` write "sept" for short dates; bare `es` groups thousands
  with a period while `es-MX`/`es-US` group like English) rather than picking a new convention.
