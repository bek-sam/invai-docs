## Acceptance criteria
1. **Spanish heading (gate issue 2).** `/digests/<weekKey>` and the `/digests` list rows in Spanish show the week in Spanish ("Semana del lun 21 sep"), using `Intl` with the app language, never the browser locale. English unchanged.
2. **Points and unchanged (gate issue 3).** On the glance grid, margin % and on-time % changes show points ("+6.9 pts" / "+6,9 pts"); a zero change shows "unchanged" / "sin cambio" with no arrow and a neutral color. Other metrics keep the relative percent; points apply only to `marginPct` and `onTimePct` (PM plan review 2; copy rows `change.pts`, `change.unchanged` in `specs/weekly-digest.md`).
3. **Refused page (gate issue 5).** A signed-in office@ opening Settings → Notifications sees a translated "You don't have access to this page. Ask the owner." / "No tienes acceso a esta página. Pídeselo al dueño." instead of "Missing permission org.manage …". `errorInfo()` maps `FORBIDDEN` for every screen, not just this one.
4. **Numbers (gate issue 5).** Plan usage renders limits with the locale's thousands separator ("10,000" / "10.000").
5. 390 px and 1440 px, en and es: no raw keys, no English in Spanish, targets ≥ 44 px.
