## Acceptance criteria
1. Every workflow: actions pinned by full commit SHA with a version comment, top-level `permissions: {}` and least per-job permissions, `concurrency`, `timeout-minutes`.
2. Every repo: a dependency audit step (pnpm audit or OSV scanner) failing on High/Critical; a secret scan (gitleaks) on push; a container scan (Trivy or Grype) of each built image where a Dockerfile exists; an SBOM (CycloneDX) artifact; a weekly scheduled run so Amazon's 30-day cadence holds without pushes.
3. Dependabot or Renovate for npm, Python (uv), GitHub Actions and Docker base images, grouped, weekly.
4. `actionlint` passes on every workflow (say how you ran it).
5. B-189 guard rules with adversarial tests; `.claude/` synced after approval only.
6. No workflow is triggered by the agent; this wave's push runs them on GitHub and the gate reports the links.
